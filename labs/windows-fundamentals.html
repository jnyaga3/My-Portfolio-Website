LAB WRITE-UP · SECURITY ANALYST

Windows Fundamentals

A practical Windows security lab completed through Hack The Box Academy as part of my Cyber Shujaa Security Analyst training. The module focused on understanding Windows systems, administration, permissions, processes, services and security controls.

Week 1 · Assignment 1 September 2026 Security Analyst Training

01 · OVERVIEW

Understanding Windows from a security perspective.

Windows Fundamentals introduced the structure and functionality of the Windows operating system from a security-focused perspective.

The module covered areas including the Windows file system, permissions, the Registry, services and processes, sessions, Windows Management Instrumentation, Microsoft Management Console, Windows Subsystem for Linux and Windows security.

The practical exercises helped me connect these concepts with the type of system information a Security Analyst may need to collect when examining a Windows workstation or server.

02 · AREAS COVERED

What I worked on.

The module brought together several Windows administration and security concepts through practical exercises.

SYSTEM STRUCTURE

Windows Architecture

Examined Windows operating-system structure, the file system and the organization of directories and system resources.

ACCESS CONTROL

Permissions & Accounts

Worked with users, groups, NTFS permissions, share permissions and Security Identifiers (SIDs).

SYSTEM INVESTIGATION

Services & Processes

Investigated Windows services and processes and examined information that can help identify system activity during a security investigation.

WINDOWS ADMINISTRATION

PowerShell & WMI

Used Windows command-line functionality, PowerShell commands and Windows Management Instrumentation to retrieve system information.

CONFIGURATION

Windows Registry

Examined Registry hives, values and data types while exploring how Windows stores configuration information.

SECURITY

Windows Security Controls

Explored security identifiers, User Account Control, application controls, startup mechanisms and other Windows security concepts.

03 · APPROACH

Learn, investigate, verify.

I approached the module by combining the provided learning material with the practical exercises. Rather than relying only on the explanations, I used the Windows environment to observe how the concepts worked in practice.

Where a command or administrative tool was required, I followed the module instructions, examined the resulting output and used that information to determine the required finding.

I also documented the commands, observations and supporting screenshots used throughout the exercises so that the investigation process could be reviewed and reproduced.

04 · KEY FINDINGS

What the lab taught me to look for.

The exercises demonstrated how much useful security information can be obtained directly from a Windows host. System configuration, permissions, services, processes, sessions and Registry information can all provide useful context during an investigation.

I also developed a better understanding of the relationship between Windows administration and security analysis. Knowing how a system normally operates makes it easier to recognise information that may require further investigation.
